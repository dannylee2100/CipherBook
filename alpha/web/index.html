CipherBook Alpha 1 · local engineering preview

One encrypted envelope at a time

Create or manually restore one identity, compare one contact through a separate trusted interaction, seal text, and move the resulting ciphertext through another application. This is an envelope utility, not a messenger or an online account.

This page does not automatically save your identity or messages. Manual encrypted-file export is optional. Clear or reload resets the interface, but browsers, operating systems, extensions, memory, crash data, downloads, backups, and clipboards may retain copies.

No temporary identity exists.

Restore encrypted identity file

Select one file that you previously created manually. CipherBook does not remember the file or passphrase.

CipherBook does not intentionally save the passphrase. Browsers, extensions, password managers, operating systems, and crash data may still retain or offer to fill it.

This public contact identifies your current CipherBook identity. People encrypt envelopes to this identity. Closing, reloading, or leaving this page loses the active identity unless you previously downloaded its encrypted identity file.

Keep this identity for later

Download an encrypted identity file before closing the page. Without it, the next identity you generate will have a different public contact, and your contacts will need to exchange and verify the new contact.

Exporting creates a passphrase-encrypted file containing the private key needed to use this same public contact again.

This identity will be lost when the page is closed or reloaded unless you download an encrypted identity file.

Public contact

  • Safe to send to the intended counterparty
  • Used to address encrypted envelopes
  • Does not decrypt messages
  • Does not restore the identity

Encrypted identity file

  • Must not be sent as a public contact
  • Contains the encrypted private identity material
  • Requires the passphrase
  • Restores the same public contact
  • Should be retained privately and not published

The encrypted identity file does not contain:

  • Counterparty contacts or verification confirmation
  • Message plaintext or message history
  • The passphrase
  • Online account information

Download in three steps

  1. Enter and confirm a passphrase.
  2. Download the encrypted identity file.
  3. Store the file and passphrase separately.

CipherBook cannot recover the file or passphrase.

A weak passphrase may be guessed offline by anyone who obtains this file.

There is no password reset. Losing the passphrase makes this file unusable. Keep the file and passphrase separately.

At least 12 Unicode code points and at most 1024 UTF-8 bytes. Leading spaces, trailing spaces, case, and Unicode form are significant. This minimum does not make a passphrase strong.

CipherBook has not started an encrypted identity-file download for this identity during this page session.

CipherBook cannot verify where the browser stored the file or whether you retained it.
